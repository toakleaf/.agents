# .agents

Personal Codex skills shared across my computers.

The `skills/` directory contains the skill definitions and their supporting files. `.skill-lock.json` records installed skill versions.

Clone it into the home directory with the personal GitHub SSH alias:

```sh
git clone git@github.com-toakleaf:toakleaf/.agents.git ~/.agents
```

Pull changes with `git pull --ff-only` before editing skills on another computer.
