---
name: git-branch-naming
description: Use when creating, renaming, or suggesting git branch names (checkout -b, push, PR branches).
---

New branches: `feature|bugfix/<team>/[<ticket>-]<slug>`.

Team: `ui/arch` for product/UI code; `ait` for AI tooling, agents, skills, and harness config.

Examples: `feature/ui/arch/R9E-94716-Vite-inspect-opt-in`, `feature/ait/R9E-12345-my-change`
